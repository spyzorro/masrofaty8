# تعديلات Masrofaty v2.22

هذه النسخة مخصصة لحل مشكلة أن GitHub كان يخرج أكثر من APK داخل نفس التحميل.

تم تعديل GitHub Actions بحيث:

- يمسح أي ملفات APK قديمة من مجلد `downloads` قبل كل بناء.
- ينسخ ملف APK واحد فقط باسم `Masrofaty-latest.apk`.
- يرفع Artifact واحد يحتوي على APK واحد فقط.
- يحدث `update.json` ليشير إلى نفس ملف APK الواحد.

التطبيق الناتج ليس أجزاء منفصلة. هو APK واحد كامل يشمل:

- المصروفات.
- قائمة المهام والتنبيهات.
- مدخرات الذهب وسعر الذهب.
- شريط التنقل السفلي بين الأقسام.

مهم: لو عندك ملفات APK قديمة في مستودع GitHub، أول تشغيل للـ Action بعد رفع هذه النسخة سيحذفها من مجلد `downloads` ويترك `Masrofaty-latest.apk` فقط.
