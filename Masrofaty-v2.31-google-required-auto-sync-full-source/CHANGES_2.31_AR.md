# تغييرات Masrofaty v2.31

## دخول Google إجباري

- عند فتح التطبيق لأول مرة، لن تظهر المصروفات أو المهام أو الذهب قبل تسجيل الدخول بحساب Google.
- لو فتحت شاشة المهام أو الذهب بدون حساب، التطبيق يرجع تلقائيًا لشاشة تسجيل الدخول.
- الهدف: منع حفظ أي بيانات محلية غير مرفوعة على Google.

## مزامنة Google تلقائية

- المستخدم لا يدخل Firebase API Key أو App ID أو Project ID أو Web Client ID من البرنامج.
- الإعدادات مدمجة في `app/google-services.json`.
- بعد تسجيل الدخول يتم تفعيل:
  - حفظ تلقائي بعد أي تعديل.
  - استرجاع تلقائي بعد تسجيل الدخول.

## الميزانية الشهرية

- الميزانية الشهرية المحددة تتطبق تلقائيًا مع بداية كل شهر ميلادي.
- عند فتح التطبيق في شهر جديد، يتم أرشفة الشهر القديم ثم تطبيق ميزانية الشهر الجديد.

## مهم

لازم تبني من النسخة الكاملة فقط، ولا ترفع فولدر `modified-files`.
