# تغييرات Masrofaty v2.30

## إصلاح Google Sync نهائيًا

- التطبيق لم يعد يحتاج إدخال `Firebase API Key` أو `Firebase App ID` أو `Project ID` أو `Google Web Client ID` من داخل البرنامج.
- الإعدادات أصبحت مدمجة داخل `app/google-services.json`.
- تمت إضافة `Google Web Client ID` الصحيح داخل ملفات الموارد كقيمة احتياطية.
- إذا كان المستخدم كتب Web Client ID غلط قبل كده، التطبيق الآن يفضل القيمة المدمجة الصحيحة.

## الحفظ التلقائي

- بعد تسجيل الدخول بحساب Google، أي تعديل في البيانات يشغل رفع تلقائي:
  - المصروفات
  - المهام
  - الذهب
  - الديون والاشتراكات والإعدادات

## الاسترجاع

- الاسترجاع من Google يدمج البيانات السحابية مع البيانات الحالية.
- رسالة الاسترجاع أصبحت تعرض عدد السجلات في السحابة وقبل/بعد الاسترجاع، عشان يظهر فورًا هل النسخة السحابية فيها بيانات أم لا.

## مهم قبل البناء

لازم ترفع الملف داخل GitHub بهذا المسار والاسم بالضبط:

```text
app/google-services.json
```

ولا تستخدم اسم:

```text
google-services(1).json
```
